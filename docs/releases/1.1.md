# DSNForge 1.1

Released from source tag `v1.1` (assembly/package version `1.1.0`), dated 2026-10-20.

DSNForge provides a Windows GUI, reusable library and CLI for Db2 for z/OS LOAD,
UNLOAD and same-server table transfer through DSNUTILU.

## Downloads

- **Setup:** `DSNForge-1.1.0-Setup-win-x64.exe` — per-user installer and uninstaller.
- **GUI:** `DSNForge-1.1.0-GUI-win-x64.zip` — portable Windows application.
- **CLI:** `DSNForge-1.1.0-CLI-win-x64.zip` — command-line client.
- **Library:** `DSNForge-1.1.0-Library-net48.zip` and `DSNForge.Core.1.1.0.nupkg`.
- **Verification:** `SHA256SUMS.txt` and `build-manifest.json` identify the packaged files
  and checked-out source commit.

## Highlights

- Saved, ordered transfer projects and editable utility cards.
- Configurable LOAD batches, MVS allocation and post-success dataset cleanup.
- FTP representations and SITE options, PREVIEW validation, live events and exportable reports.
- English and Persian documentation, project logo and application icon.
- Public builds do not depend on proprietary DB2 binaries; live connections still require
  the installed Microsoft provider and appropriate host privileges.

## Operational notes

Windows x64 and .NET Framework 4.8 are required. The Microsoft provider is not bundled.
The installer and binaries are unsigned. Native formats need an appropriate layout;
automatic CSV packing targets text columns. Jobs are sequential. Utility row progress
is unavailable until SYSPRINT returns. An interrupted utility may still be running on
the host and is never automatically replayed.

See the bilingual README, user guide and CHANGELOG in the repository for details.
