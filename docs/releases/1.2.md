# DSNForge 1.2 — profile and wizard workflows

Released 2026-10-20.

- Separate connection-profile manager: DB2 + FTP, clone/edit, manual tests and save-after-failure confirmation.
- Per-service environment, Windows-encrypted Manual, and runtime-prompt passwords.
- Task wizard: profile, catalog/SQL, files, CSV layout, DDL and cards.
- Modal execution wizard: runtime overrides, encrypted Remember, progress/errors and exportable text statistics.
- `.dbmeta` sidecars with editable table/tablespace creation SQL, catalog attributes and LOAD cards.
- Streaming SELECT-to-CSV export, field selection/encoding/trim and explicit NULL representation.
- AES ZIP creation, automatic archive detection, password retry and safe extraction.
- Profile-aware library runner and CLI; legacy projects remain readable.

Builds and tests run from this Git tag in GitHub Actions. Component ZIPs, library NuGet,
installer, SHA-256 checksums and source manifest are separate assets. Binaries are unsigned.

Validation: 55 offline regression assertions; modal-form screenshot smoke tests; read-only live
catalog/schema checks and a one-row synthetic SELECT export to CSV + metadata + encrypted ZIP.
No production LOAD or CREATE TABLE was used to validate these changes. New provider adapters
and every host-side numeric/date conversion have not been live-tested.

See [the wizard guide](../WIZARDS.md) for provider requirements, DPAPI portability,
DDL reconstruction limits, native record requirements and cancellation behavior.
